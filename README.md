# A股 V3.0 回测系统（初始基线）

初始资金300000元，单笔风险预算1%，信号次日开盘交易，结构止损，100股整手，佣金万分之一且无最低5元。示例滑点5bp为假设；印花税示例为卖出0.05%，**历史回测必须按交易日期修正税率**。

CSV必需字段：date,open,high,low,close,volume。统一复权口径，不可混用。运行：`pip install -r requirements.txt && python -m pytest -q && python run.py --data-dir data`。

当前仅为单股票MA5/MA10金叉+MACD基线，尚未实现28股组合资金管理、涨跌停成交约束、停牌、公司行动、历史税费、样本外验证和完整风险验收。没有可靠历史数据不生成绩效数字。不构成投资建议。

## V3.0 数据采集模块（2016-01-01 至 2026-11-17）

`python -m src.collect_data --start 20160101 --end 20261117`

* 原始不复权日线写入 `data/<ticker>.csv`（交易执行价格只使用此目录）。
* 前、后复权供应商参考日线分别写入 `data_adjusted/qfq`、`data_adjusted/hfq`；不使用未来调整后的前复权价格作为历史成交价。
* 独立复权因子尝试通过新浪接口抓取，保存至 `data_factors`；缺失明确标记为 `unavailable`，绝不将四舍五入价格比率冒充精确复权因子。
* 数据质量报告位于 `reports/data_quality.json`；重复日期、无效OHLC、负成交量、跨日期范围、缺字段、非交易日周末等均会阻止对应股票的数据写入。
* 股票池清单 `config/stocks.txt` 当前**仅21个已知代码**（7核心+14扩展），还缺7个扩展代码。程序刻意拒绝少于28只的全量采集，避免误称完成。
* GitHub Actions 工作流每天北京时间16:30尝试运行，但由于研究截止日固定为2026-11-17，此版本不会采集该日之后的数据；未来滚动更新需显式更改截止日。
* 本采集模块不包含历史完整停牌日历、ST状态、公司行动现金分红与送转明细；这些必须另行核验，不能据此宣称已具备真实可交易回测。
* 注意：数据供应商接口可能变动，运行环境必须能够访问对应数据源；GitHub Actions 的实际执行结果需在仓库 Actions 页面验证。
